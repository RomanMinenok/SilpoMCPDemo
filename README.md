# Сільпо / зріз

Локальний прототип персональної статистики покупок через Silpo MCP. Застосунок
показує топ-10 товарів за останні 12 місяців і детальну історію кожного товару.

Репозиторій **не містить чеків, покупок, токенів або даних акаунта**. Кожен
користувач входить у власний акаунт Сільпо через OAuth, а дані завантажуються
окремо для його тимчасової локальної сесії.

## Запуск

Потрібен Node.js 20 або новіший.

    npm install
    npm run dev

Відкрийте http://127.0.0.1:4173, натисніть «Увійти через Сільпо» й завершіть
авторизацію. Для іншого порту:

    PORT=3000 npm run dev

## Команди

- npm run dev — локальний сервер і OAuth callback.
- npm test — тести аналітики та санітизації відповідей.
- npm run lint — синтаксична перевірка JavaScript.
- npm run build — створює готовий локальний runtime у dist/.

## Як працює приватність

- OAuth 2.1 + PKCE виконує офіційний MCP-клієнт.
- Для кожного браузера створюється випадкова HttpOnly-сесія з SameSite=Lax.
- OAuth-токени, реєстраційні дані клієнта й отримані покупки зберігаються тільки
  в пам’яті Node.js-процесу.
- Сервер не записує MCP-відповіді на диск і не логуватиме їх.
- Вихід або завершення процесу видаляє сесію; неактивні сесії спливають за 8 годин.
- У браузер не передаються домашні адреси, URL електронних чеків чи дані акаунта.

## Архітектура

- src/app.js — стани входу/завантаження та два клієнтські екрани.
- src/server.mjs — локальний HTTP-сервер, сесії та OAuth callback.
- src/lib/silpo-mcp.js — OAuth provider і виклики Silpo MCP.
- src/lib/normalize-orders.js — allowlist-перетворення MCP-відповідей у UI-модель.
- src/lib/analytics.js — чиста агрегація топу й підсумків.
- tests/ — лише синтетичні fixtures; реальні покупки в тестах заборонені.

Рейтинг визначається кількістю чеків із товаром; пакети виключаються. Це дозволяє
коректно порівнювати вагові й штучні товари.
